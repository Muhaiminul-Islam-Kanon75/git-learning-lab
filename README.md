# Git Learning Lab

A Python CLI application to learn:

- Git
- GitHub
- GitHub Actions
- CI/CD
- Branching
- Rebasing
- Merge conflict resolution

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
python3 -m app.main
```

The web frontend starts at http://127.0.0.1:8000. The application opens the URL automatically when a browser is available.

## Run Tests

```bash
pytest
```
